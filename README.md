# Homebrew Keep3

Official Homebrew tap for [Keep3](https://github.com/taobaorun/keep3).

After the first release is promoted, install Keep3 with:

```sh
brew install --cask taobaorun/keep3/keep3
```

Release pull requests are generated by Keep3's protected release workflow.
Every change is checked with Homebrew's official `brew test-bot` tap syntax
validation before it can merge into `main`.
